# Flows Knowledge Index

## Concepts

* [Change Lifecycle](change-lifecycle.md) - One Change carries accountable intent through Decision, global Planning, Implementation, Integration, Git/delivery boundaries, and outcome disposition while every discrepancy remains resolved, Change-accounted, or safely unknown.
* [Claim Wait and Observation Flow](artifact-claim-wait-heartbeat.md) - Runtime grants one exact bounded Claim per Work Item attempt, waits on overlap instead of forcing conflict, and treats leases/heartbeats as operational observations rather than semantic truth.
* [Decision to Planning Flow](decision-to-planning.md) - Planning may consume only one exact Decision candidate whose required Results produce a passing Exit Report and whose approval was appended after final authority and freshness guards.
* [Migration Audit](migration-audit.md) - Historical source reduction is complete; active migration now replaces legacy Loop-exit contracts with exact Candidate, Check, Result, Policy, and Report identity while preserving Runtime, trace, worker, and effect foundations.
* [Planning to Implementation Flow](planning-to-implementation.md) - Passed-and-appended Planning produces worker-ready Work Items and Workbench requirements; Runtime provisions exact execution and Implementation accepts only candidate-bound realization evidence.
* [Production Readiness Audit](production-readiness-audit.md) - CodeWiki remains private pre-production software; release requires clean Loop-exit migration, exact authority/identity, OKF v0.2, external Pi/provider/OCI proof, and separately approved publication.
* [Resume Context Boundary](resume-context-boundary.md) - Pi owns conversation/session compaction; CodeWiki resumes semantic project work from exact Change Trace, WorkState, Knowledge, source/Git, policy, and recovery refs rather than private cognition.
* [Runtime Work Item Claim Flow](runtime-work-unit-claims.md) - Passed Planning yields worker-ready Work Items; Runtime provisions exact Workbenches, appends Claims, supervises isolated Assignments, and feeds Worker Report evidence into Implementation without granting acceptance.
