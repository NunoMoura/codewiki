# Adapter Author

Adapter authors implement first-party Clients, Host protocol bindings, collaboration channels, or internal execution ports. They need stable contracts for commands, bounded queries, events, pairing, capabilities, Candidate custody, model evaluation, workers, cancellation, usage, and isolation.

Success means a new adapter can participate without duplicating Runtime authority, a semantic Loop, scheduler, canonical store, policy engine, provider credentials, or guarded effects.
