# Stories Knowledge Index

## Concepts

* [Maintain Fresh Intent](intent.md) - As a maintainer or agent, I want CodeWiki to capture and challenge current project intent before planning or code changes, so future work uses agreed solutions instead of rediscovering goals from chat history or raw diffs.
* [Navigate With Low Token Cost](navigation.md) - As an agent or maintainer, I want compact trace-backed status first so I can choose the right next context without loading the whole knowledge base or trace history into the session.
* [Prevent Horizontal and Vertical Drift](drift.md) - As a maintainer, I want CodeWiki to detect contradictions between intent, docs, loop outputs, traces, evidence, tests, code, and Git proof so the knowledge base remains trustworthy.
* [Sanitize Historical State](sanitation.md) - As a maintainer, I want hot CodeWiki state to stay small while full history remains recoverable.
* [Use Loop-Governed Automation](automation.md) - As a user, I want an agent to advance CodeWiki work automatically while staying bounded by explicit loop, exit-condition, budget, and approval boundaries, so progress can continue without losing alignment with my intent.
