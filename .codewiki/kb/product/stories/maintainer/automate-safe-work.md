# Automate Safe Work

As a maintainer, I want CodeWiki to advance compatible work automatically so routine progress survives browser, terminal, or channel disconnection while unsafe progression remains blocked or explicitly stopped.

## Acceptance signals

- Server reconnects Clients to durable Runtime operations rather than private conversation state.
- Runtime selects, Claims, isolates, starts, retries, integrates, runs stage Gates, stops safely, and applies the fixed Decision → Planning → Implementation → Review lifecycle.
- Managed Pi and MCP-mediated Worker activity use Runtime-owned isolated Workbenches and exact Candidate Manifests.
- Review may be fully automated with independent Model and Code Checks; human Review Evidence is optional unless project Checks require it.
- Missing capability, stale state, external divergence, incomplete Evidence, or absent authority never silently relaxes policy or crashes the service.
