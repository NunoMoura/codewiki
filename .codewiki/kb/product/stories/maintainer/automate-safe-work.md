# Automate Safe Work

As a maintainer, I want CodeWiki to advance compatible work automatically so routine progress survives browser, terminal, or channel disconnection while unsafe progression remains blocked.

## Acceptance signals

- Server reconnects Clients to durable Runtime operations rather than private conversation state.
- Runtime selects, Claims, isolates, starts, retries, waits, integrates, verifies, blocks, and routes eligible work.
- Managed Pi and MCP-mediated Worker activity use Runtime-owned isolated Workbenches and exact Candidate Manifests.
- Missing capability, stale state, external divergence, incomplete Evidence, or absent authority never silently relaxes policy.
